The four states worth designing for
Everything else on this screen is a text box. These are the parts that go wrong.
1 · A number whose zero means the opposite
Maximum resubmissions
How many times a returned application may be resubmitted.
0 0 means unlimited, not none
The live value is 0 today. Written as a bare number box, an admin who wants to forbid resubmission types 0 and gets the exact opposite. The line under the field is not decoration.
2 · Editable, but it will not do anything yet
WhatsApp delivery Waiting on client
No provider is connected. Turning this on only queues messages.
Three settings are in this state — WhatsApp, the GSTIN and the public directory. The chip says so on the row rather than leaving the admin to discover it by trying.
3 · A switch that publishes member data
Make the member directory public?
Anyone on the internet will be able to browse the list of member firms without logging in.
Cancel Make it public
One switch here changes who can see member firms. It is the only setting on the screen that asks before it commits.
4 · Everyone who is not a super admin
settings.manage is super-admin only. The nav already hides what a role cannot use, so this screen does not appear at all rather than appearing read-only — consistent with every other screen in the app.
